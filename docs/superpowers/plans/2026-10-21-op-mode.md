# OP Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A toolbar OP tool that stakes an observation post and shows the 3D map from it: fixed camera, swipe to look, pinch to magnify, item taps still open menus, readout measured from the OP.

**Architecture:** A small patch to `@rnmapbox/maps` exposes Mapbox's free camera (`setFreeCamera`). A memory-only `useOp` store holds the OP state; `useOpCamera` places the free camera from it; `OpGestures` wraps the map with Pan/Pinch; `MissionMap` wires picking, guards every normal camera move while in OP mode, and shows `OpBar`.

**Tech Stack:** Expo SDK 57, RN 0.86, @rnmapbox/maps 10.3.8 (Mapbox 11.23.1) + patch-package, Zustand, react-native-gesture-handler 2.32, Reanimated 4.5, `@expo/ui` (Slider), jest-expo.

**Spec:** `docs/superpowers/specs/2026-10-21-op-mode-design.md`

## Global Constraints

- The iOS native method must stay **exactly** as on `spike/op-mode` (commit `cfde992`): spec `setFreeCamera(viewRef: Int32 | null, values: ReadonlyArray<number>) => Promise<Object>`, values `[lon, lat, altitudeM, pitch, bearing]`; ObjC `RCT_EXPORT_METHOD(setFreeCamera:(nonnull NSNumber*)viewRef values:(NSArray *)values resolve:… reject:…)`; Swift `setFreeCameraWithValues(_:resolver:rejecter:)`. The user's current dev build has it; changing it forces a rebuild.
- Never add Co-Authored-By or any trailer to commits. Conventional Commits, single quotes, never run prettier.
- Before each commit: `npx tsc --noEmit 2>&1 | grep "error TS"` (empty), `npx expo lint --no-cache` (0 problems), and the full `npx jest` (`Test Suites:` all passed) before the last commit of each task.
- Crosshair glyph is `CrosshairGlyph`; the crosshair action button is `CenterButton` (via `PlaceBar`).
- Values: eye height 5–250 m, default 10; pitch 0–85, entry 80; magnification 1–3; ground refresh 1000 ms; turn 0.25°/pt, tilt 0.2°/pt; OP haze range `[2, 20]` (normal 3D `[0.8, 8]`); terrain exaggeration setting default 1.5, valid 1–3; exit eases to zoom 15, `THREE_D_PITCH`, heading = OP bearing.
- Copy: toolbar label `OP` (icon `binoculars`), help `Look out over the 3D map from a spot you pick.` (group `read`); bar `Eye 10 m`, facing e.g. `045° GRID`, zoom `2.0×`, `Exit`; readout `FROM OP`.
- Skip Android testing (the Android native code is written but not run).

## Review Focus

1. Switching missions or leaving the map while in OP mode — the next map opens normally (OP exits on unmount). Test in Task 6.
2. Zoom, North and Recenter buttons pressed in OP mode — nothing moves the camera. Test in Task 6.
3. No terrain loaded at the OP yet (`queryTerrainElevation` → null) — camera placed at 0 m + eye, then corrected when the refresh finds ground. Test in Task 4.
4. Exiting while magnified — the map returns at 1× with gestures back. Test in Task 8.
5. A menu opened from an item tap in OP mode, then closed — no camera move on open or close. Test in Task 6.
